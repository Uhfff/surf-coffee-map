# Surf Coffee: зоны аренды

Спутниковая карта Москвы (от Садового кольца до ТТК и ещё около 3 км, без севера) с предварительной оценкой зон для аренды помещения.

- Слои: теплокарта зон, топ-15, Surf Coffee и конкуренты, метро, ТЦ, вузы.
- Данные: © участники OpenStreetMap (ODbL), снимки Esri. Оценка предварительная, без реальной проходимости.
- Заметки сохраняются в браузере (localStorage). Перенос между устройствами: «Сохранить .json» / «Загрузить .json».
